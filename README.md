# cavalry

Every human rescue of the fleet, interruptions, manual edits, killed runs, and rephrased prompts, recorded, classified, and answered with a drafted hook or rule meant to make that rescue the last of its kind.

## What this is

A takeover is the moment the setup failed a human, and no platform counts rescues per rule or per role, so the same rescue gets ridden again and again. Cavalry records each rescue as it happens and classifies it against the instructions and roles involved. Every entry drafts the hook or rule that would retire its class, turning a pattern a human once noticed by memory into a query anyone can run. The boundary with its siblings is one sentence. Prod handles the rescues a machine can make, cavalry the ones that needed a human.
